# Awaitility Learning Lab

A hands-on Java project exploring [Awaitility](https://github.com/awaitility/awaitility) through a simple asynchronous order processing application.

## Goals

- Understand asynchronous programming in Java.
- Explore threads and concurrency.
- Learn how to test asynchronous operations.
- Understand Awaitility's polling, conditions, and timeouts.

## Technologies

- Java 21
- Maven
- JUnit 5
- Awaitility
